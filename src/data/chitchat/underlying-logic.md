# 是非對錯

### 法學家對錯觀

基於事實的對錯認知，做錯事情的人就是錯的。

### 經濟學家對錯觀

基於成本的對錯認知，以社會總成本來考量對錯，力求以最小成本解決爭議點。

### 商人對錯觀

誰損失大就是誰的錯。

### 人性

是個體追求生存&繁衍的基準。

### 道德

是用來約束個體人性達成群體繁榮的基準。

### 法律

維護群體存在的最低道德底線。

### 博弈的智慧

保持共贏心態，遇善則善，愈惡則惡。

### 定力

定力是人生的智慧──最終的勝利，常常是時間的勝利，是長期主義的勝利。

### 選擇的智慧

學會選擇，常常就是學會放棄：選擇一個，放棄其他。選擇有時比努力重要，但放棄有時比選擇更重要，我們應當勇敢選擇，然後享受好處，承擔壞處。人生的悲劇，往往來自看著前方，又想著後方，最後無路可走。

# 思考問題

### 真實

獨立於人的判斷，客觀存在。

### 觀點

對事實的看法。

### 信仰

內部完全自洽的邏輯體系。信仰內部邏輯自成一格，且無法被改變。

### 立場

被位置和利益影響的觀點。若發生爭執點的根因是立場不同，除非你與對方有相同位置與利益，否則是不可能達成共識的。

### 注射式洗腦

前設性質的認知操作，好比：”胖的人，真的比較懶嗎?”。透過虛假建立的偽事實來對你進行認知操作，事實上並沒有一個具客觀性的實驗證明這件事。

PS: 這道技巧被廣泛用在 社群行銷 上面，常常是觸發認知焦慮的戰術。

### 基本邏輯素養

1. 證有不證無。

證明事情存在，不代表反面就不存在。

2. 以偏不概全

不要以偏概全。

3. 證有靠舉例

要證明靠舉例而不是個人觀點。

4. 概全靠推理

要概全，利用自己的邏輯思維證明。

# 個體進化

- 人生商業模式 = 能力 X 效率 X 槓桿
- 能力 = 有效率的勤奮，解法是刻意練習。刻意練習的關鍵是不斷重複稍微困難的任務，從而獲得最高效的進步。
- 效率 = 選擇的智慧，選擇怎麼正確運用你的時間。
- 槓桿 = 團隊 產品 資本 影響力

# 理解他人

有時候他人提出的並不是真正的問題，而是一個他試圖用來解決真正問題的答案。這種時候，盲目順著他的思路去回答他的問題，可能反而會害了他。我們應該做的，是先去理解他為甚麼會提出這個問題。

# 社會協作

想要擁有更多財富，就應該想盡一切方法，提高自己的稀缺性。

比如，對於個人來說，你要思考的問題應該是：

—我是否擁有非常稀缺的能力？

—我是否在公司最稀缺的部門？

—我是否擁有部門最稀缺的資源？

—我現在擁有的稀缺性，未來還能繼續稀缺嗎？

只有不斷讓自己變得稀缺，你才能擁有財富分配權，獲得更多財富。
